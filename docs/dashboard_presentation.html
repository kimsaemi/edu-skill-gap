PROBLEM

개인화 근거 및 갭 분석

입력 누락, 검색 결과 부재, 데이터 로딩 실패 시 사용자가 다음 행동을 명확히 인지할 수 있어야 합니다.

서비스 거버넌스 명시

자가 학습 기록의 세션 보관 정책, 점수 자동 상향 조작 금지, 문의 창구(GitHub Issue)를 제공해야 합니다.

PERSONALIZATION

추천 산식과 역량 공백(Gap)

사용자 입력

  • 목표 직무 (인사·총무·경영지원)
  • 실제 수행 업무 (안정적 task_id 기반 선택)
  • 역량별 현재 수준 (1~5점 자가 척도)
  • 숙련도별 목표 수준 (입문 3, 기초 4, 실무 5)

계산 및 제시 기준

  • 보완 필요 단계: max(목표 수준 - 현재 수준, 0)
  • 연계 역량 다중 충족: 여러 필요 역량을 동시에 다루는 과정 우선
  • 하이브리드 랭킹: 갭 크기, 딥러닝 임베딩 유사도, 시수 반영
  • 설명 가능성: 연결된 역량명과 매핑 근거를 카드에 직접 노출

※ 대시보드는 자가 진단을 공식 평가 결과로 사칭하지 않으며, 데이터 매핑 근거를 투명하게 제시합니다.

TRUST & TRANSPARENCY

과정 카드의 신뢰 정보

표시 항목 사용 목적 데이터 필드 및 정책
기관, 시수, 수강료, 형태 기본 비교 및 수강 요건 파악 provider, duration_hours, price, education_type
원천 플랫폼 및 수집 시점 데이터 출처 및 기준일 확인 source_provider, collected_at (임의 최신 확인일 사칭 금지)
원문 바로가기 링크 실제 일정·비용·개강 여부 확인 course_url (교육기관 공식 사이트로 직접 이동)
자가 완료 체크 및 진척도 학습자의 개인 학습 관리 브라우저 세션 보관 (역량 점수 자동 상향 조작 금지)

※ 수료 인정 여부는 교육기관의 공식 기준이 절대적이며, 본 대시보드의 완료 처리는 자기 학습 기록용입니다.
