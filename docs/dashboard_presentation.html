PERSONALIZATION

추천 근거와 역량 공백

입력

  • 목표 직무
  • 실제 수행 업무
  • 역량별 현재 수준 1~5
  • 숙련도에 따른 목표 수준

계산과 제시

  • 목표 수준에서 현재 수준을 뺀 보완 필요 단계
  • 선택 업무와 연결된 NCS 역량
  • 여러 역량을 함께 충족하는 과정 우선
  • 보완 필요 단계와 시수를 반영한 Top 3

대시보드는 사용자의 자기진단을 실제 평가 결과로 표현하지 않습니다. 추천 이유와 데이터 매핑 근거를 함께 표시합니다.

TRUST

과정 카드의 신뢰 정보

표시 항목사용 목적데이터 필드
기관, 난이도, 시수, 수강료과정 선택 전 기본 비교`institution_name`, `course_level`, `training_hours`, `course_fee`
플랫폼과 수집 유형데이터 출처 확인`source_platform`, `source_type`
수집일정보 최신성 판단`collected_at`
원문 링크일정, 비용, 모집, 수료 조건 재확인`course_url`

수료 여부는 교육기관의 기준이 우선입니다. 대시보드의 완료 처리는 학습자의 세션 기록입니다.
