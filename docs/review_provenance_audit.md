## 1. Executive Summary (핵심 감사 결과 요약)

2026년 10월 22일, `data/kfo_courses/` 디렉토리에 7개 교육 플랫폼의 수강생 리뷰 DB(482,078건)가 업로드됨에 따라, 원본 보존 원칙하에 데이터의 수집 출처(Provenance), 크롤링 로그, API 연동 흔적 및 실제 수강생 작성 여부에 대한 **전수 심층 감사(Full Provenance Audit)**를 수행하였습니다.

### 📌 감사 최종 결론: **전체 리뷰 482,078건은 '실제 수강생 후기'가 아닌 '규칙·템플릿 기반의 합성(Synthetic) 데이터'로 확정**

1. **실제 수집 근거 부재**:
   - 원본 크롤링 스크립트, 수집 요청 로그, 웹사이트 응답 캐시, API 연동 명세가 일체 존재하지 않습니다.
   - 2026-10-21 일자 사전 감사(`docs/COURSE_REVIEWS_AND_RATINGS_AUDIT_REPORT.md`)에서 확인된 바와 같이, 원본 DB(KPC, GSEEK, KMA, 휴넷, 멀티캠퍼스, KFO)에는 실제 후기 텍스트가 0건이었으며, 이번에 추가된 DB는 별도로 생성되어 주입된 파일입니다.
2. **합성(Synthetic) 데이터의 결정적 통계적 증거**:
   - **페르소나 3등분 분할**: 모든 7개 플랫폼에서 `전공자 : 직장인 : 학생` 비율이 정확하게 **33.3% : 33.3% : 33.3%**로 완벽히 균등 배분되어 있습니다.
   - **평점의 일률적 확률분포**: 7개 플랫폼 전수에서 평균 평점이 **4.00 ~ 4.02점**으로 수렴하며, 5점(~40%), 4점(~35%), 3점(~15%), 2점(~6%), 1점(~4%)의 동일한 난수 발생 분포를 따릅니다.
   - **생성 일자의 인위적 균등성**: 모든 리뷰의 작성일자가 `2025-01-01 08:00:00`부터 `2025-12-31 23:29:03`까지 365일에 걸쳐 완벽한 시간적 균등 분포를 보입니다.
   - **문형 템플릿(Slot-filling) 반복**: 동일한 문장 템플릿에 교육 카테고리 명칭만 치환한 리뷰 텍스트가 휴넷 72%, KPC 67%, KMA 61% 등 대규모로 중복 반복되었습니다.
3. **서비스 및 추천 시스템 적용 원칙**:
   - 본 리뷰 데이터를 **"실제 수강생 후기"로 사용자나 대시보드에 표기하는 것은 허위 정보 제공이 되므로 엄격히 금지**합니다.
   - 데이터 식별자 및 메타데이터 상에 `provenance_status = 'SYNTHETIC_UNVERIFIED'`, `is_synthetic = True` 플래그를 영구 고정합니다.
   - **기존 추천 엔진(Ko-SRoBERTa + BM25 + KSA ML 분류 모델)의 점수에 본 리뷰 평점을 직접 가산/반영하지 않으며, 독립적인 R&D/파이프라인 테스트용 데이터셋으로만 격리 관리**합니다.

## 2. 6대 핵심 검증 항목 심층 분석

### 1) 원본 웹사이트 URL 존재 여부
- **검증 결과: `미포함 (부재)`**
- 리뷰 DB의 `courses` 테이블 컬럼은 `[course_id, title, category, subcategory, review_count, average_rating, created_at]` 7개로 제한되어 있으며, 실제 원본 웹페이지 URL이나 리뷰 상세 페이지 URL 컬럼이 존재하지 않습니다.
- (참고: 기존 8,645건 통합 코퍼스 `education_courses_integrated.parquet`에는 강좌 상세 URL이 존재하나, 이는 코퍼스 메타데이터일 뿐 리뷰 페이지 URL이 아님)

### 2) 실제 크롤링 스크립트 및 실행 로그 존재 여부
- **검증 결과: `로그 및 스크립트 전무 (부재)`**
- 프로젝트 내 `scripts/` 디렉토리 및 git commit 히스토리를 전수 검사한 결과, 수강생 리뷰 48만 건을 스크래핑한 Selenium, Playwright, BeautifulSoup, Scrapy 스크립트 및 HTTP Request 로그 파일이 단 1건도 존재하지 않습니다.

### 3) 공공/민간 API 수집 여부
- **검증 결과: `API 수집 자료 아님 (부재)`**
- 고용24(HRD-Net), K-MOOC 등 국내 교육 공공 API는 수강생 리뷰 본문을 대외에 오픈 API 형태로 제공하지 않습니다. 또한 B2B 교육기관(휴넷, 멀티캠퍼스, KPC, KMA) 역시 수강생 리뷰 API를 개방하지 않으므로 API 수집 데이터가 아닙니다.

### 4) AI/Faker/규칙 기반 합성 데이터 판정 근거
- **검증 결과: `100% 합성(Synthetic) 데이터로 판정`**
- 본 감사에서 추출한 구체적 템플릿 반복 실례:
  * **패스트캠퍼스 (83회 반복 문구)**:
    > *"전반적인 강의 구성이 알차고 AI 생산성 설명도 직관적이어서 개념 잡기에 참 좋았습니다. 다만 뒤쪽 심화 실습과 응용 문제는 난이도가 다소 있어서 혼자 복습하는 시간이 조금 더 필요했습니다..."*
  * **휴넷 (298회 반복 문구)**:
    > *"중요도가 높은 리더십 파트의 구조적 분석과 디테일한 팁이 정말 큰 도움이 되었습니다. 전공자 기준에서도 취약한 부분을 정밀하게 보완할 수 있는 명품 강의라고 생각합니다..."*
  * **KPC (698회 반복 문구)**:
    > *"전공 서적으로만 접하던 오프라인, 인재키움프리미엄훈련 내용을 실무 관점에서 깔끔하게 연결해주셔서 매우 유익했습니다. 커리큘럼의 깊이와 완성도가 상당히 높아서 수강 내내 높은 만족감을 느꼈습니다..."*
- 위 문장들은 사전에 정의된 약 50~100개의 긍정/중립/부정 문장 템플릿의 슬롯(`{category}`)에 강좌 분류명을 치환하고 난수를 발생시켜 조립한 전형적인 규칙 기반(Rule-based) 합성 데이터 생성 기법의 산물입니다.

### 5) Persona의 원본 수집값 여부
- **검증 결과: `임의 난수 생성값 (Synthetic Random Assignment)`**
- 7개 플랫폼 전체 482,078건의 페르소나 집계:
  * **학생**: 161,170건 (33.43%)
  * **전공자**: 160,709건 (33.34%)
  * **직장인**: 160,199건 (33.23%)
- 실제 B2B 직무교육(예: KMA, KPC) 수강생의 95% 이상은 직장인이며, 학생이나 비직장인 전공자가 33%씩 균등하게 존재할 수 없습니다. 따라서 `persona` 컬럼은 데이터 생성 시 3개 클래스를 1:1:1로 균등 할당한 합성 변수입니다.

### 6) 사이트 이용약관 및 수집 권한 검토
- **검증 결과: `실제 크롤링 저작권 침해 이슈는 없으나, 표기 책임 준수 필요`**
- 실제 교육 사이트의 수강생 리뷰를 크롤링한 것이 아니라, 개발팀 또는 외부에서 시뮬레이션용으로 인공 생성한 데이터이므로 외부 사이트 이용약관 위반(웹 스크래핑 금지 조항 등) 리스크는 없습니다.
- 그러나 이를 "실제 수강생이 남긴 피드백"으로 대외 공개하거나 서비스 UI에 표기할 경우 '표시·광고의 공정화에 관한 법률' 및 연구 윤리 위반 소지가 발생하므로, 반드시 **'합성 데이터(Synthetic Dataset)'**임을 명시해야 합니다.

## 4. 최종 조치 사항

1. **격리 및 식별자 고정**:
   - `reviews_integrated.parquet`에 `is_synthetic = True`, `provenance_status = 'SYNTHETIC_UNVERIFIED'`를 부여하여 데이터 소비자가 즉시 인지하도록 조치함.
2. **개인정보 비식별화(Masking)**:
   - 가상으로 생성된 이름일지라도 실존 인물 명칭과의 혼선을 방지하기 위해 `user_name_masked` (예: `이*은`, `김*일`) 형태로 전수 마스킹 변환 완료.
3. **추천 모델 보호**:
   - `course_review_summary.parquet`에 `include_in_recommendation = False` 컬럼을 명시하여 실제 프로덕션 추천 엔진(Ko-SRoBERTa + BM25)의 가중치로 진입하는 경로를 원천 차단함.
