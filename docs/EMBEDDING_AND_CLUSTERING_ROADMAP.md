## 2. 세부 단계별 실행 계획 (Next Steps)

### 1단계: 임베딩 벡터 추출 및 저장 (Offline Pipeline)

- 대상: 8,645건 교육과정의 `[제목 + 교육소개 + 학습목표]` 텍스트 풀
- 배치 크기: 32 (GPU / CPU 호환 모드 지원)
- 출력: `data/hr/output/embeddings/course_embeddings_sroberta.parquet` (768차원 부동소수점 벡터)

### 2단계: 다차원 유사도 분석 (Semantic Similarity)

1. **과정 간 유사도 (Course-to-Course):** '이 과정을 들은 학습자에게 가장 유사한 다른 교육 추천'
2. **NCS 능력단위-과정 유사도 (NCS-to-Course):** 공식 NCS 마스터(`ncs_ksa_master.csv`)의 능력단위 명세 텍스트와 교육과정 텍스트 간 코사인 유사도 계산

### 3단계: 토픽모델링 및 K-Means 군집화 (Topic & Clustering)

- **BERTopic 활용:** 임베딩 벡터 기반 c-TF-IDF를 활용하여 데이터 스스로 형성하는 10~15개 실무 토픽 자동 추출
- **K-Means 군집화:** 실루엣 계수(Silhouette Score)와 엘보우 기법(Elbow Method)을 통해 최적의 군집 수 $k$ 결정 (예: $k=8 \sim 12$)
- **토픽/군집별 상위 핵심 키워드 도출:** 각 군집의 중심점(Centroid)에 가장 가까운 핵심 어휘 목록 산출
