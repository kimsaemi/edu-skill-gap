# HTML 대시보드 '자료 질문' 기준값 점검

`node scripts/check_html_rag.js` 실행 결과 (대상: `hr_career_platform_v2_2026-11-16.html`).

## 계산 방식
- 브라우저 안에서만 계산합니다(서버·AI 호출 없음). 결과는 찾은 근거를 그대로 보여 줍니다.
- 검색 대상: 문서 조각 113개(13종) + 교육과정 4995개(같은 제목 1번, 제외 목록 50개·이벤트 안내 제외)
- 글자 2·3개 묶음 TF-IDF 코사인. 흔한 말·어미(처음이에요, 싶어요 등)는 뺍니다.
- 문서와 교육과정은 따로 점수를 매깁니다. 교육과정은 최대 3건, 인사·업무 관련 단어가 있는 질문에만 보여 줍니다.
- 직급(주임~부장)을 물으면 직급별 성장 가이드의 해당 직급 조각에 +0.3을 줍니다.

## 기준값
- 문서 ≥ 0.1 (설정 막대로 바꿀 수 있음), 교육과정 ≥ 0.2
- 질문 수가 적어 확정값이 아닙니다.
