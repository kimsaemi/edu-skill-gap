# AI 상담 업무 연결 기준값 점검

`scripts/calibrate_chat_threshold.py` 실행 결과(`data/hr/output/chatbot/threshold_calibration.json`)에서 숫자를 옮겼습니다.

## 점수 계산
- 업무 점수 = 의미 유사도(질문 ↔ 업무명) + 0.03 × BM25(업무명·쉬운 설명·지식·기술)
- BM25는 90개 업무 안에서 드문 단어에 높은 가중치를 주므로 '직무'·'관리' 같은 흔한 단어 가산점은 두지 않습니다.

## 결과 종류와 기준값
| 결과 | 조건 | 화면 |
| --- | --- | --- |
| 업무 연결 | 점수 ≥ 0.8, 또는 점수 ≥ 0.5이면서 1·2위 차이 ≥ 0.15 | 그 업무의 기본 추천 3개 |
| 업무 후보 | 점수 ≥ 0.5이지만 1·2위가 비슷함 | 업무 후보 버튼 2개 + 질문 검색 결과 |
| 검색 | 점수 < 0.5 | 질문 검색 결과 |
| 범위 밖 | 의미 유사도 최고값 < 0.38이고 인사 관련 단어 없음 | 안내 문구만 |

## 근거
- 90개 업무명을 그대로 넣었을 때 자기 업무 1위: 90/90, 결과 종류: {'task_match': 90}
- 인사와 무관한 질문 10개의 의미 유사도 최고값: 0.3751 (범위 밖 기준 0.38)
- 인사 질문 12개의 의미 유사도 최저값: 0.4165
- 1·2위 차이 기준은 아래 인사 질문 표에서 업무가 분명한 질문과 1·2위가 비슷한 질문을 가르는 값으로 정했습니다.
  질문 수가 적어서 확정값이 아니며, 애매하면 업무를 단정하지 않고 후보를 보여 주는 쪽으로 정했습니다.
