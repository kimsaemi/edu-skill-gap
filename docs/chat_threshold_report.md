# 챗봇 업무 매핑 임계값(Threshold) 실증 캘리브레이션 보고서

## 1. 캘리브레이션 개요 및 목적
- **기존 문제**: 인위적 키워드 가산점(+0.28) 및 임의의 기준값(0.55)으로 인해 '직무급제 도입' 질의가 '직무 순환'으로 오매핑되고, '안녕 반가워' 같은 일상어에 비관련 교육이 추천되는 문제 발생.
- **개선 목표**:
  1. 인위적 키워드 가산점을 전면 배제 (전체 업무명 일치 시에만 최대 +0.05).
  2. 무관 질문 최고 점수와 실제 인사 실무 질의 점수 분포를 실측하여 수학적·경험적 최적 임계값 도출.

## 3. 임계값 결정 근거
1. **업무 매핑 기준값 (`TASK_SIMILARITY_THRESHOLD = 0.42`)**:
   - 무관 질문의 최고 유사도 점수는 **0.3751** ('안녕 반가워')입니다.
   - 따라서 `0.42` 이상이어야만 무관 질의가 업무로 잘못 매핑되는 것을 원천 차단할 수 있습니다.
   - 실제 인사 실무 질문의 평균 점수는 **0.6932**로, 임계값 `0.42`를 안정적으로 상회합니다.
2. **범위 밖(Out-of-Scope) 기준값 (`OUT_OF_SCOPE_THRESHOLD = 0.38`)**:
   - 질문 점수가 `0.38` 미만이고 인사 관련 키워드가 포함되지 않은 경우, 과정 검색 대신 안내 문구("이 서비스는 인사 교육과정 추천용이에요. 예: '평가 면담을 잘하고 싶어요'")를 제시하여 엉뚱한 과정 추천을 방지합니다.
