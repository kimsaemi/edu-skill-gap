## 3. 대표적 실제 추천 개선 사례 비교

- **2단계 Cross-Encoder 추천 3위**: `[휴넷] 인재 밀도를 UP시키는 성과 평가 ＆ 보상 전략` ⭕ *(정상 대체)*

  - 사유: HRD 담당자의 교육 설계에 일반 이메일 작성 강좌가 진입.
