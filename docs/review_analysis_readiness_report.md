## 2. 세부 텍스트 분석(NLP) 활용 타당성 및 제약사항 검토

출처 감사 결과 본 리뷰 데이터가 **합성(Synthetic) 템플릿 데이터**로 판명됨에 따라, 각 분석 영역별 가능성과 한계를 엄밀하게 구분하여 정의합니다.

### 1) 별점 및 평점 분포 분석
- **분석 가능성: `기술 검증(PoC) 용도로만 가능`**
- **한계점**: 모든 플랫폼에서 평균 4.01점, 5점(40%), 4점(35%), 3점(15%), 2점(6%), 1점(4%)의 정형화된 다항분포 난수로 생성되었으므로, 강좌 간 평점 차이는 플랫폼의 실제 품질 차이를 대변하지 못합니다.
- **활용 방안**: 집계 파이프라인의 성능 검증 및 시각화 대시보드 레이아웃 렌더링 테스트에 한정하여 사용합니다.

### 2) 리뷰 감성 분석 (Sentiment Analysis)
- **분석 가능성: `매우 높음 (NLP 모델 벤치마크 최적)`**
- **근거**: 템플릿 문장이 문법적으로 완벽한 한국어로 구성되어 있고, 긍정 후기(칭찬, 실무 도움), 부정 후기(난이도 부담, 복습 시간 부족, 자료 부족)의 어휘가 뚜렷하게 나뉘어 있습니다.
- **활용 방안**: 한국어 사전 기반 감성분석(KNU 감성사전)이나 KoBERT/KcELECTRA 기반 감성 분류 모델의 추론 파이프라인 성능 평가 및 F1-Score 측정용 테스트베드로 유용합니다.

### 3) 부정적 후기 핵심 키워드 및 토픽 모델링 (BERTopic / LDA)
- **분석 가능성: `가능 (시뮬레이션 토픽 추출)`**
- **키워드 예시**:
  * 긍정 토픽: `실무 연계`, `핵심 요약`, `구조적 분석`, `트렌드 파악`, `자격증 취득`
  * 부정 토픽: `심화 실습 난이도`, `강의자료 부족`, `모바일 배속 재생`, `퇴근 후 피로/시간 부족`
- **주의 사항**: 추출된 토픽을 "실제 사용자의 요구사항"으로 보고서에 기술해서는 안 되며, "데이터 생성 알고리즘에 반영된 가상 페르소나별 시나리오 키워드"로 명시해야 합니다.

### 4) 수강생 페르소나별 의견 차이 분석
- **경고 및 원칙**:
  * 본 데이터의 페르소나(`학생`, `전공자`, `직장인`)는 실제 사용자의 속성이 아니라 균등하게 부여된 임의 레이블입니다.
  * 따라서 "학생 집단이 직장인 집단보다 강의에 불만이 많았다"와 같은 결론을 도출하는 것은 **통계적 허위 상관(Spurious Correlation)**에 해당하므로 절대 수행하지 않습니다.

## 3. 기존 추천 엔진 보호 대책

현재 프로젝트의 핵심 엔진인 **Ko-SRoBERTa + BM25 하이브리드 추천 및 KSA 머신러닝 분류 모델**은 직무 적합성과 역량 갭(Skill Gap)을 정밀하게 계산하고 있습니다.

### 🛡️ 보호 원칙 및 통제 방안
1. **가중치 오염 차단**:
   - `course_review_summary.parquet`에 `include_in_recommendation = False` 컬럼을 기본값으로 고정하였습니다.
   - 실제 추천 스코어 계산 수식에 리뷰 평점 가중치를 합산하지 않습니다.
   ```python
   # [권장] 추천 점수 계산 시 방어 로직
   if course_meta.get('provenance_status') == 'SYNTHETIC_UNVERIFIED':
       # 합성 데이터는 추천 점수 산정에서 완전 제외
       final_score = base_semantic_score * 0.7 + bm25_score * 0.3
   ```
2. **평점 결측 강좌의 안전한 처리**:
   - 리뷰가 없는 고용24 140건 강좌의 경우, `average_rating_calculated = NaN`(결측치)으로 보존하며 0점으로 왜곡하지 않습니다.
   - 0점으로 처리할 경우 고용노동부 공식 국비지원 강좌의 추천 순위가 부당하게 최하위로 밀리는 심각한 편향(Bias)이 발생하므로 이를 방지했습니다.
3. **독립된 A/B 시뮬레이션 환경 구축**:
   - 리뷰 평점을 활용한 랭킹 재정렬(Re-ranking)은 본 서비스가 아닌 가상의 '실험적 A/B 테스트 환경(Experimental Sandboxing)'에서만 제한적으로 수행하도록 설계합니다.
