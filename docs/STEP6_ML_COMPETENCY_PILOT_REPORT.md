## Executive Summary (초보자 & 비전공자를 위한 핵심 요약)

### 1. 어떤 머신러닝 모델을 학습했나요?
- **모델 A (TF-IDF + One-vs-Rest Logistic Regression)**: 강의 소개글에 등장하는 한국어 전문 명사들의 빈도와 가중치를 계산하여 8개 직무역량에 속할 확률을 각각 독립적으로 판별하는 모델입니다.
- **모델 B (Ko-SRoBERTa 768차원 임베딩 + One-vs-Rest Logistic Regression)**: 딥러닝 언어 모델(Ko-SRoBERTa)이 추출한 768차원의 문맥 벡터를 입력받아 문맥의 의미적 유사성을 바탕으로 8개 직무역량을 판별하는 모델입니다.

### 2. 어떤 데이터를 학습에 사용했나요?
- 8,645건 통합 교육과정 중 기존 규칙 기반으로 역량이 매핑되어 있던 **4,966건의 교육과정**을 학습에 활용했습니다.
- **주의 (중요)**: 이때 사용된 정답은 사람이 일일이 검수한 절대 정답(Ground Truth)이 아니라, 키워드 규칙으로 자동 추출된 **‘약한 라벨(Weak Label)’**입니다.
- **미매핑 강좌(3,679건)**는 역량이 없어서 0인 것이 아니라 규칙에 걸리지 않은 미확인 강좌이므로, 억지로 '모든 역량 0(오답)'으로 주입하지 않고 학습에서 제외하여 모델 왜곡을 방지했습니다.

### 3. 두 모델의 결과 차이는 어떠한가요?
- **모델 A (TF-IDF)**: **Macro-F1 0.7573, Micro-F1 0.8260, ROC-AUC 0.9490**  
  직무별 고유 어휘(예: '채용', '근로기준법', '자산관리' 등)가 뚜렷한 역량에서 매우 높은 정밀도(Precision 0.7583)를 보이며 기존 약한 라벨과의 일치도가 우수했습니다.
- **모델 B (Ko-SRoBERTa)**: **Macro-F1 0.5766, Micro-F1 0.6885, ROC-AUC 0.8900**  
  문맥의 유연성을 포착하여 재현율(Recall 0.7749)은 높았으나, 인사·총무 직무 간 어휘의 미세한 경계를 지나치게 넓게 해석하여 다소의 위양성(False Positive)이 발생했습니다.
- **학습 및 추론 속도**: 모델 A는 1.58초(학습)/0.017ms(추론), 모델 B는 기존 768차원 임베딩을 재사용하여 **0.18초(학습)/0.004ms(추론)**라는 초고속 성능을 달성했습니다.

### 4. ‘검증된 성능’과 ‘검증되지 않은 성능’의 구분
- **검증된 성능**: 기존의 규칙 기반 자동 매핑 시스템이 부여한 라벨을 머신러닝 모델이 얼마나 충실하게 재현하고 일반화하는지에 대한 **‘약한 라벨 일치도(Fidelity/Agreement)’**입니다.
- **검증되지 않은 성능**: 실제 도메인 전문가(HR/총무 실무자)가 이 강좌를 직접 평가했을 때의 **‘진짜 실무 적합도(Ground Truth Accuracy)’**는 아직 인간 평가 라벨이 없으므로 검증되지 않았으며, 섣불리 90% 이상의 정확도를 가졌다고 주장해서는 안 됩니다.

### 5. 추천 시스템에 추가할 가치가 있나요?
- **매우 높은 가치가 있습니다 (단, 가중치 결합 또는 네거티브 게이트 형태로 활용).**
- 특히 특정 직무 역량(예: '노무준법')에 대한 추천 요청이 들어왔을 때, 머신러닝 예측 점수가 극히 낮은(P < 0.15) **비관련 강좌(전체 코퍼스의 55~58%)를 사전에 차단(Negative Gatekeeper)**하는 강력한 방어 필터로 활용할 수 있습니다.
- 또한 기존 규칙 매핑에서 누락되었던 **3,679건의 미매핑 강좌 중 1,174건의 고확신(≥0.8) 역량 강좌를 새롭게 발굴**하는 데 기여했습니다.

### 6. 다음 작업 우선순위
1. **[우선순위 1] 소규모 전문가/사람 평가 표본(50~100건) 블라인드 검증**: 규칙 라벨과 모델 예측이 엇갈린 21건 및 미매핑 발굴 강좌에 대해 실제 정답 여부 확인.
2. **[우선순위 2] 추천 엔진 네거티브 필터(Soft Gate) A/B 테스트**: 기존 하이브리드 추천 엔진 점수를 파괴하지 않고, `comp_ml_prob < 0.1`인 경우 랭킹 감점(Penalty) 옵션 추가.
3. **[우선순위 3] Streamlit 탭 11 시각화 및 인터랙티브 역량 진단 툴 실사용 피드백 수집**.

## 3. 데이터 누출(Data Leakage) 차단 분할

8,645건 코퍼스 분석 결과, 개설 회차(1기, 2기...), 플랫폼 간 복제 강좌(GSEEK, 휴넷, KPC 등)로 인해 **중복 강좌명이 3,033건(정규화 기준 4,023건)**에 달했습니다.  
만약 일반 무작위 분할(`train_test_split`)을 사용하면 동일 강좌가 Train과 Test에 분산되어 평가 지표가 과대 포장되는 치명적 **데이터 누출(Data Leakage)**이 발생합니다.

### Group-aware Split 적용 결과
정규화된 강좌명(`norm_title`)을 그룹 키로 사용하여 `GroupShuffleSplit`을 2단계로 수행했습니다.

```
전체 코퍼스 (8,645건)
 ├── 미매핑 코퍼스 (3,679건) ──> 추론 및 신규 잠재역량 발굴용
 └── 약한 라벨 코퍼스 (4,966건, 2,830개 고유 강좌 그룹)
      ├── Train Set (70%): 3,412건 (고유 그룹 1,981개)
      ├── Validation Set (15%): 785건 (고유 그룹 424개)
      └── Test Set (15%): 769건 (고유 그룹 425개)

[데이터 누출 원천 차단 검증]
- Train ∩ Val 그룹 중복: 0건
- Train ∩ Test 그룹 중복: 0건
- Val ∩ Test 그룹 중복: 0건 (100% 상호 배타적 분리 완료)
```

## 5. 오매핑 의심 109건 및 불일치·불확실 강좌 심층 분석

### 5.1 오매핑 의심 109건에서의 예측 결과
- 109건은 기존 규칙에서 '문서', '관리', '인재' 등의 단순 단어로 인해 기술/자격 강좌(예: "Claude로 100배 빠르게 만드는 의료 문서", "소방안전관리자 2급")가 HR/총무 역량으로 잘못 매핑된 샘플입니다.
- **분석 결과**: 모델 A는 1건, 모델 B는 3건만 역량 없음(0건)으로 판정하고 대부분을 여전히 양성으로 판정했습니다.
- **원인 분석**: 머신러닝 모델이 규칙 기반 약한 라벨로부터 학습했기 때문에, 규칙이 가지고 있던 어휘 편향(의료 문서도 '문서' 단어 때문에 역량으로 라벨링됨)을 모델 역시 일정 부분 학습했음을 보여줍니다. 이것이 바로 **약한 라벨 학습의 본질적 한계**이자, 사람에 의한 독립 검증이 왜 필요한지를 단적으로 입증합니다.

### 5.2 규칙 매핑 vs 머신러닝 예측 불일치 (위양성 의심 21건)
- 기존 규칙에서는 역량으로 자동 매핑되었으나, **두 ML 모델 모두 역량 없음(0개)으로 평가한 강좌가 21건** 발견되었습니다.

## 6. 하이브리드 추천 엔진 연동 사전 분석 (시뮬레이션)

기존 운영 추천 엔진(`unified_hybrid_recommender.py`)을 파괴하지 않고, 머신러닝 예측 점수를 어떻게 안전하게 결합할 수 있는지 시뮬레이션했습니다.

### 6.1 기존 점수와의 상관관계 및 중복성 분석
- Ko-SRoBERTa 딥러닝 임베딩 점수와 모델 B 예측 점수는 동일한 768차원 임베딩을 피처로 공유하므로 **상관관계(Spearman r = 0.72~0.85)가 높아 정보 중복(Collinearity)**이 발생합니다.
- 반면 모델 A(TF-IDF 명사 토큰)의 예측 점수는 시맨틱 점수와의 상관계수가 0.52~0.65 수준으로 적절하여, **시맨틱 검색의 약점(키워드 불일치)을 보완하는 독립적인 앙상블 신호**로 훨씬 적합합니다.

### 6.2 네거티브 게이트(Negative Gatekeeper) 방어 효과
특정 역량 질의(예: '노무준법') 시, 해당 역량의 머신러닝 예측 점수가 극히 낮은($P < 0.15$) 비관련 강좌를 사전에 필터링하는 시뮬레이션을 수행했습니다.
