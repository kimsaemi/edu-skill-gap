   꼭 맞는 최적의 강의를 찾아주는 맞춤형 강의 추천 시스템(넷플릭스 형태) 개발"

2. 프로젝트 추진 배경 및 목표
--------------------------------------------------------------------------------
기존 직업훈련 및 교육 플랫폼들은 다음과 같은 불편함이 있었습니다:
 1) 교육 사이트마다 정보가 뿔뿔이 흩어져 있어 일일이 찾아다녀야 함
 2) 검색창에 "인사 급여"를 치면 엉뚱한 강의가 나오거나 같은 강의가 1회차, 2회차로 
    수십 개씩 도배됨
 3) 내게 진짜 필요한 핵심 역량을 키워주는 강의인지 내용 기반으로 추천받기 어려움

=> 목표: 여러 사이트의 교육 데이터를 하나로 모으고, 자연어 처리(NLP)와 AI 기술을 
   활용하여 사용자의 질문/상황에 가장 알맞은 강의 1~5위를 족집게처럼 추천해 주는 
   추천 엔진과 대시보드를 구축합니다.

--------------------------------------------------------------------------------
3. 데이터 분석 진행 방식 (어떻게 진행해 왔나요?)
--------------------------------------------------------------------------------
프로젝트는 크게 [수집 ➔ 정제 ➔ 분류 ➔ 검색/추천 모델링 ➔ 화면 표출]의 5단계로 진행되었습니다.

[1단계: 데이터 수집 (크롤링 및 API 연동)]
  - 초기: 295개의 고용24 중심 표본 데이터로 파일럿 분석 시작
  - 확장: 고용24, KPC(한국생산성본부), KMA(한국능률협회), 휴넷, 패스트캠퍼스, 
          GSEEK(경기도평생학습포털) 등 6대 교육 플랫폼에서 총 8,645건의 인사·총무 
          관련 교육과정 데이터 전수 수집 완료

[2단계: 데이터 정밀 전처리 (노이즈 청소)]
  - 불필요한 HTML 태그, 스타일 코드, Base64 인라인 이미지, 시스템 에러 문구 제거
  - 학원 홍보용 상용구(예: "국비지원 100% 무료", "수강후기 이벤트" 등) 필터링
  - 대용량 데이터 처리 속도를 위해 Parquet 형식(압축 저장)으로 표준화

[3단계: 강의 성격별 자동 서랍 분류 (군집화)]
  - 8,645개 강의 내용을 컴퓨터가 스스로 읽고, 비슷한 직무끼리 8개의 서랍(클러스터)으로 
    자동 분류 (AI/DX, 직무기초, 보안, 리더십, 안전보건, 경영전략, 어학, 인사노무)

[4단계: 3가지 점수를 섞은 하이브리드 추천 엔진 구축]
  - "단어 일치도" + "의미적 문맥 유사도" + "수강생 평점"을 합산하여 최종 순위 결정
  - 도배 방지, 무료 강의 점수 보정 등 실무적 결함 3가지를 수학적으로 해결

[5단계: 웹 대시보드(Streamlit) 시각화]
  - 분석 결과와 추천 기능을 누구나 마우스 클릭으로 테스트해볼 수 있도록 웹 화면 구현

4. 사용된 핵심 기법 및 기술 스택
--------------------------------------------------------------------------------
초보자분들도 이해하기 쉽게 기법별 역할을 설명해 드립니다:

1) 형태소 분석 (한국어 쪼개기): Kiwi 형태소 분석기
   - "인사급여관리"라는 단어를 컴퓨터가 잘 이해하도록 쪼개는 기술입니다.
   - 인사·총무 분야 전문 단어(통상임금, 4대보험, 주52시간 등 24종)를 사용자 사전에 
     추가하여 오탈자나 단어 쪼개짐 오류를 방지했습니다.

2) 키워드 검색 엔진: TF-IDF & BM25
   - 사용자가 검색한 단어가 강의 제목이나 내용에 얼마나 자주, 중요하게 등장하는지 
     계산하는 전통적이면서도 가장 확실한 검색 기술입니다.

3) 의미 기반 유사도 분석: LSA (TruncatedSVD) & Ko-SRoBERTa (딥러닝 파일럿)
   - 검색 단어가 강의 제목에 똑같이 없더라도, "문맥상 뜻이 비슷한가?"를 파악합니다.
   - 예: "월급 계산"을 검색했을 때 "급여 및 원천징수 실무" 강의를 찾아냄
   - 현재는 고속 연산을 위해 통계 기반 LSA(100차원)를 사용 중이며, 최신 한국어 딥러닝 
     AI 모델인 Ko-SRoBERTa(768차원)를 400개 표본에 시험 적용 완료한 상태입니다.

4) 비지도학습 군집화: K-Means Clustering (k=8)
   - 사람이 일일이 라벨을 붙이지 않아도, 강의 설명문의 어휘 유사도를 바탕으로 
     전체 강의를 8개의 큰 직무 그룹으로 자동 묶어주는 머신러닝 기법입니다.

5) 하이브리드 추천 공식 & 결함 보정 기법
   - 기본 공식: (LSA 문맥 유사도 × 50%) + (BM25 단어 일치도 × 35%) + (평점 × 15%)
   - [보정 1] Min-Max 정규화: BM25 점수가 너무 커져서 문맥 점수를 집어삼키는 현상을 
     막기 위해 모든 점수를 0~100점 사이로 통일
   - [보정 2] 베이지안 평점 결측 보정: 평점 시스템이 없는 공공/무료 강의가 억울하게 
     0점 처리되는 것을 방지하기 위해 중립 점수(80점)를 기본 부여
   - [보정 3] 중복 제거(Deduplication): KMA나 KPC처럼 동일 강좌가 1회차~10회차까지 
     상위권을 도배하는 것을 막고 최우수 1건만 추천

6. 앞으로 우리가 해야 할 일 (Next Steps)
--------------------------------------------------------------------------------
새로 오신 팀원분과 함께 다음 단계 작업을 진행할 예정입니다:

1) 딥러닝 임베딩(Ko-SRoBERTa) 8,645건 전수 확대
   - 현재 400개 표본에만 적용되어 있는 고성능 트랜스포머 AI 임베딩을 8,645개 전체 
     강의에 적용하여 추천의 정밀도를 한 차원 더 끌어올립니다.

2) 팀원 4인 블라인드 만족도 평가 (인적 정성 검증)
   - 알고리즘 점수뿐만 아니라, 실제 사람이 보았을 때 "어떤 방식(BM25 vs AI 모델)의 
     추천이 더 마음에 드는가?"를 블라인드 테스트로 채점하고 검증합니다.

3) 사용자 맞춤형 세부 필터 기능 완성
   - "무료 강의만", "온라인/주말 강의만", "초급/중급 난이도" 등 학습자가 원하는 
     조건을 골라볼 수 있는 필터 옵션을 추천 엔진과 대시보드에 결합합니다.

4) 최종 보고서 작성 및 발표 자료 준비
   - 프로젝트 결과물 요약 보고서와 프레젠테이션(PPT) 작성
