# 🎯 고객용 역량 자기점검 & 맞춤 교육 추천 서비스 (Customer Dashboard)

본 폴더는 인사·총무·경영지원 재직자를 위한 **고객용 대시보드(Customer Dashboard)** 전용 공간입니다.

---

## 📂 폴더 구조

```
customer_dashboard/
├── streamlit_customer.py    # 고객용 대시보드 메인 구현 파일 (Streamlit)
├── app.py                   # 폴더 내 바로 실행용 진입점
└── README.md                # 폴더 안내 문서
```

---

## 🚀 로컬 실행 방법

```bash
# 방법 1: 고객용 대시보드 직접 실행 (권장)
streamlit run customer_dashboard/streamlit_customer.py

# 방법 2: 폴더 내 app.py 실행
streamlit run customer_dashboard/app.py

# 방법 3: 루트 app.py를 통한 실행
streamlit run app.py
```

## 🌟 주요 기능 및 화면 구성

1. **내 역량 점검**:
   - 담당 직무(인사, 총무, 경영지원), 경력구간, 실제 수행업무, 애로사항, 학습목표 설정
   - 8~12개 행동 기반 척도(1~5점 + NA/UNCERTAIN) 문항 자기점검
   - 현재 자기평가 vs 설정 목표 가로 막대 비교 차트 및 우선 보완 역량 Top 3 도출
2. **맞춤 교육 추천**:
   - 부족 역량(Gap)과 학습 조건(예산, 형태, 주당 학습시간)을 결합한 실제 8,645건 코퍼스 추천
   - 강좌별 추천 사유 및 실제 커리큘럼 키워드 근거 제시
   - 타 플랫폼 동일 강좌 대체 수강처 및 조건 부합 여부 안내
3. **나의 학습 보관함**:
   - 관심 교육 저장 및 최대 3개 강좌 나란히 비교
   - 개인 학습 메모 및 학습 진행 상태(예정/학습중/완료) 관리
   - 이전 진단 결과와 비교할 수 있는 재점검 히스토리 보존

## 🔒 보안 및 공개 배포 원칙

- **비로그인 세션 격리**: 사용자의 입력, 진단 결과, 보관함은 브라우저 세션(`st.session_state`) 단위로 격리되며 서버에 영구 저장되거나 타 사용자와 공유되지 않습니다.
- **자원 최적화**: 8,645건 코퍼스와 768차원 임베딩은 `@st.cache_resource`로 메모리에 1회만 상주하여 중복 로딩 없이 620ms 내외로 고속 추론을 제공합니다.
- **면책조항**: 본 대시보드는 공개된 교육 메타데이터 기반 학습 가이드이며, 각 교육의 저작권 및 수강신청 권한은 해당 교육기관에 있습니다.
