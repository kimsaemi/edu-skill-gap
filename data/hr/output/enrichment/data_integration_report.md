## 4. STEP 3 & STEP 4. 데이터 통합 및 검색용 데이터(`search_text`) 준비

### 1) 통합 표준 스키마 (13개 컬럼)
```text
1. global_course_key   : 과정 고유 식별키
2. course_name         : 교육과정명
3. source_platform     : 수집 플랫폼
4. learning_objectives : 교육목표 (검증된 본문만 포함)
5. course_description  : 과정 소개글
6. curriculum          : 회차별 커리큘럼 / 강의목차
7. ncs_code            : NCS 직무 세분류 코드
8. training_hours      : 교육시간 (시수)
9. total_course_fee    : 총 교육비
10. learner_cost       : 학습자 자부담금
11. source_url         : 원본 출처 공식 웹사이트 URL
12. text_source_status : 텍스트 품질 상태 (VERIFIED_FULL / PARTIAL_TEXT / METADATA_ONLY)
13. search_text        : 검색 및 임베딩 전용 순수 텍스트 코퍼스
```

### 2) `search_text` 구성 원칙
- **문장 유사도 왜곡 방지**: 비용(수강료)과 교육시간은 필터링(조건 검색)용 수치 변수이므로 문장 유사도 분석을 왜곡하지 않도록 `search_text`에서 제외했습니다.
- **결합 규칙**: `[과정명] // [교육목표] // [과정소개] // [커리큘럼]` 중 실제로 검증된 텍스트만 결합하여 노이즈를 차단했습니다.

### 1) TF-IDF / BM25를 지금 바로 시작할 수 있는가?
👉 **네, 즉시 시작할 수 있습니다!**  
우리가 만든 [`hr_search_corpus.csv`](file:///d:/26_강의자료/프로젝트2_교육/data/hr/output/enrichment/hr_search_corpus.csv) 파일의 `search_text` 컬럼에 불필요한 숫자나 잡음 없이 깨끗한 교육명, 목표, 커리큘럼 텍스트가 완벽하게 정제되어 준비되었습니다.

### 2) 팀원 4명 협업 가이드 (다음 주력 과제):
- **팀원 1 (데이터 엔지니어링)**: `hr_search_corpus.csv`의 `search_text`를 형태소 분석기(Okt/Mecab)로 불용어(Stopwords) 제거 및 토큰화
- **팀원 2 (검색 알고리즘)**: `scikit-learn`의 TfidfVectorizer 및 `rank-bm25` 패키지를 이용한 키워드 검색 스코어 함수 구현
- **팀원 3 (AI 언어모델)**: `Sentence-BERT`(KoSimCSE)를 활용하여 사용자 질문과 교육과정 간 코사인 유사도 벡터 연산 구현
- **팀원 4 (Streamlit 대시보드)**: 대시보드에 검색창을 만들고, 위 2번과 3번 알고리즘의 결과를 결합한 **Top 3 추천 카드 뷰** 렌더링
