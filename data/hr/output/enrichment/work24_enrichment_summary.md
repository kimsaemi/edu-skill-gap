## 3. 필드별 수집 성공률 및 결측 상태

- **훈련 시작·종료일**: 8건 중 **8건 확보 (100%)**
- **모집 정원 / 기관 ID**: 8건 중 **8건 확보 (100%)**
- **수강료(교육비)**:
  - 국민내일배움카드 5건: **5건 확보 (100%, 47,520원 ~ 50,490원)**
  - 사업주훈련 3건: API 응답 내 수강료 필드 미제공 (0원 표기 또는 결측 처리)
- **자부담금**: API 응답 미제공 (결측 처리)
- **교육목표 및 커리큘럼**: 상세 API 서비스 미인가로 인해 0건 (억지 생성 없이 **결측 유지**)

## 4. 고용24 전체 96건 확대 적용 평가

1. **훈련일정 및 수강료 수집 (즉시 확대 가능)**:
   - 고용24 사업주훈련 50건 및 국민내일배움카드 46건(총 96건)에 대해 본 파이프라인을 그대로 적용하여 일괄 수집이 가능합니다.
2. **텍스트 분석(추천/검색)용 상세정보 수집 (단계적 진행 권장)**:
   - 훈련일정 데이터에는 텍스트(단원, 목차, 상세설명)가 없습니다.
   - 고용24 포털에서 '과정/기관정보' API(`310L02`, `311D01`) 사용 승인을 받은 후 96건 전체에 대한 텍스트 수집 확대를 권장합니다.
