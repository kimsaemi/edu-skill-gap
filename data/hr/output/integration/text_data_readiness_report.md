## 4. 최종 판정 및 향후 분석 추진 권고사항

### [판정] TF-IDF와 BM25 분석을 바로 시작해도 되는가?
### 👉 **판정: `CONDITIONAL HOLD (조건부 보류 및 2-트랙 진행 권고)`**

#### [판정 근거]
1. **문서 길이의 극단적 부족 및 어휘 희소성 (Sparsity)**
   - 전체 295개 과정 중 **92.54%(273건)**가 상세설명과 교육목표 없이 평균 24자의 제목 단독으로 구성되어 있습니다.
   - 이 상태로 TF-IDF와 BM25를 실행하면, 대부분의 문헌에서 키워드 빈도가 1회 이하로 측정되어 BM25의 문서 길이 정규화 계수가 왜곡되며, "인사", "노무", "실무"와 같은 극소수 빈출 표제어 외에는 검색 매칭이 되지 않는 **단순 문자열 일치 검색기** 수준으로 퇴화합니다.
2. **사전 기획 문서(`AI_추천_및_텍스트분석_고도화계획.txt`)의 지침 부합**
   - 이미 기획안의 `1단계. 데이터 심화 수집: 교육과정 상세 커리큘럼 웹 크롤링`에서 "제목만으로는 알 수 없는 강의 세부 기술/지식 텍스트 전수 확보"가 필요함을 명시하고 있습니다.

### [향후 권장 실행 로드맵 (2-Track Strategy)]

```
[현재 상태 (295건)] ──┬── Track A: 즉시 파이프라인 프로토타입 (검증용)
                      │     └─ 295건 search_text(제목 위주)로 TF-IDF / BM25 코드 구조만 베이스라인 검증
                      │
                      └── Track B: 상세 커리큘럼 웹 크롤링 (본 분석 고도화) [권장]
                            ├─ 1) Deep URL 보유 199건(HUNET, KPC, KMA 등) 상세 커리큘럼 크롤링
                            ├─ 2) 고용24 96건 상세 페이지 URL 복원 및 커리큘럼 보강
                            └─ 3) 풍부한 텍스트(200~500자) 기반 정밀 BM25, K-Means 군집화, klue/bert 임베딩 가동
```

1. **Track A (프로토타입 검증용 베이스라인 분석)**:
   - 현재 생성된 `search_text`를 활용하여 알고리즘 파이프라인(토큰화, TF-IDF 매트릭스, BM25 인덱싱)의 동작 가능 여부만 먼저 단위 테스트(PoC)로 구축합니다.
2. **Track B (실제 성능 확보를 위한 상세 커리큘럼 수집)**:
   - 199개 과정의 상세 URL을 크롤러로 호출하여 `강의 소개(Overview)`, `주차별 세부 목차(Syllabus)`, `학습 목표`를 수집한 후, 정밀한 TF-IDF / BM25 / 한국어 임베딩(klue-bert) 추천을 진행할 것을 강력히 권고합니다.
