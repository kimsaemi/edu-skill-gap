## 1. 검색용 텍스트 정제 결과

원본 Parquet 데이터셋은 100% 무결성을 위해 일절 수정하지 않고, 검색 및 임베딩 입력에 최적화된 별도의 정제 데이터셋(`education_courses_search_cleaned.parquet`)을 구축했습니다.

### 1.1 정제 규칙 및 조치 사항
1. **Base64 인라인 이미지 완전 제거**:
   - `data:image/...;base64,...`, `[이미지] https://...base64,...` 등 수십만 자에 달하는 원시 바이너리 텍스트를 정규식으로 완전 박멸.
2. **HTML 태그 및 엔티티 정제**:
   - `<script>`, `<style>`, 모든 HTML 태그 및 `&nbsp;`, `&amp;` 등의 엔티티를 표준 공백/문자로 치환.
3. **소개글-학습목표 중복 결합 방지**:
   - `course_intro`와 `learning_goals`가 동일하거나 포함 관계인 경우(1,394건), 검색 텍스트 합성 시 1회만 반영하여 어휘 빈도 왜곡 차단.
4. **반복 행정·마케팅 문구 제거**:
   - `"귀 사는 중소기업이신가요?..."`, `"[수강신청하기] 버튼이 보이지 않을 경우..."`, `"본 과정은 온오프라인 통합과정입니다..."` 등의 정적 공지문 제거.
5. **실제 교육목표 및 커리큘럼 100% 보존**:
   - 주차별 강의 내용, 모듈별 실습 목차 등 실제 교육 역량을 나타내는 텍스트는 원본 그대로 보존.
6. **부족한 정보에 대한 임의 생성 금지**:
   - 본문이 없는 제목 위주 강좌에 대해 임의의 가짜 텍스트를 생성하지 않고, 원본 상태를 보존한 채 품질 태그(`TITLE_ONLY`)를 부여.

## 2. NCS·KSA 매핑 점검 결과

### 2.1 공식 NCS 코드 vs 프로젝트 자체 KSA 역량 ID 명확한 구분
기존 데이터셋의 `ncs_code` 컬럼에는 두 가지 체계가 혼재되어 있었으며, 이를 다음과 같이 엄격히 구분하여 정의합니다:

1. **공식 국가직무능력표준(NCS) 분류 코드 (총 140건 보유)**:
   - 고용노동부/한국산업인력공단이 제정한 표준 8자리 세분류 코드:
     - `02020201` (총무 - 46건)
     - `02020202` (일반사무 - 21건)
     - `02020101` (인사 - 20건)
     - `02010101` (경영기획 - 14건)
     - `02020302` (비서 - 2건) 등
   - 기존 공공 API 수집 데이터에서 제공된 공식 표준 코드입니다.
2. **프로젝트 자체 KSA 역량 식별자 (총 4,966건 매핑)**:
   - 본 프로젝트의 직무 분석 프레임워크에 따라 정의된 맞춤형 역량 ID:
     - `COMP_GA_01` (총무/자산관리 - 2,611건)
     - `COMP_MGMT_01` (경영기획/사업계획 - 1,021건)
     - `COMP_SEC_01` (비서/의전 - 413건)
     - `COMP_LABOR_01` (노사관계/근로기준 - 283건)
     - `COMP_HR_01` (인사기획 - 180건), `COMP_HR_02` (채용/온보딩 - 169건) 등
3. **일반 과정 (`GENERAL`, 3,539건)**:
   - HR/총무/경영지원 핵심 키워드 룰에 부합하지 않아 특정 KSA로 자동 분류되지 않은 일반 소양/타직무 강좌.

### 2.2 'VERIFIED' 상태에 대한 정의 및 오매핑(False Positive) 자동 탐지
- **주의 및 사실 확인**: 기존 데이터의 `VERIFIED` 표시는 **사람이 직접 전수 검증한 것이 아니라, 특정 키워드 룰셋에 의해 100% 자동 매핑(Rule-based Auto-matched)된 결과**입니다.
- **오매핑 자동 탐지 결과**:
  - IT/소프트웨어, 바리스타, 미용, 용접, 클라우드 등 HR/총무와 무관한 교육과정이 제목 속의 우연한 어휘(예: '관리', '업무', '효율')로 인해 `COMP_GA_01` 등으로 자동 분류된 사례가 **총 109건 탐지**되었습니다:
    - `HUNET_Y00368335`: `백엔드 개발자를 위한 Java 바이브코딩` → `COMP_GA_01` (VERIFIED) [오매핑]
    - `HUNET_Y00354149`: `처음 시작하는 자바 프로그래밍-초급` → `COMP_GA_01` (VERIFIED) [오매핑]
    - `HUNET_Y00353446`: `AWS 자격증 클라우드` → `COMP_HR_01` (REVIEW_NEEDED) [오매핑]
    - `HUNET_Y00340784`: `파이썬 업무자동화 w. Github Copilot` → `COMP_GA_01` (VERIFIED) [오매핑]
- **교훈 및 원칙**:
  - **"NCS 코드나 KSA 코드가 같다고 해서 해당 교육의 적합성이 검증된 것은 절대 아니다."**
  - 사람의 정성적 라벨링 없이 규칙 기반 매핑만으로 '검증 완료'라고 주장할 수 없으며, 향후 STEP 5-2 임베딩 모델의 시맨틱 유사도를 통해 이러한 어휘 매칭 오분류를 정밀 필터링해야 합니다.

## 3. 동일 교육과정 다회차 중복 처리 기준 및 결과

### 3.1 식별 기준 체계
- **교육기관 (`provider`)**: 서로 다른 교육기관은 과정명이 같아도 독립된 교육으로 엄격히 분리 (임의 병합 금지).
- **과정명 (`title`)**: 과정의 기본 명칭.
- **기본 과정 ID (`base_course_id`)**: `course_uid`에서 개설 회차 번호를 분리한 고유 강좌 번호 (예: `KPC_46985_149706` → `KPC_46985`).
- **커리큘럼 시그니처 (`curric_hash`)**: 과정명이 같더라도 커리큘럼 구조가 다르면 별도 교육과정으로 판별.

### 3.2 검색 표출 시 다회차 묶음 처리 (Deduplication on Display)
- 검색 결과 상위 10개 표출 시, 동일 기관의 동일 강좌 다회차 개설건은 **가장 매칭 점수가 높은 대표 1개 회차만 노출**하고 비어 있는 순위 슬롯을 차순위 서로 다른 강좌로 자동 보충(Backfilling).
- 이로써 `Q02`(근로기준법)에서 단 1개 과정이 상위 8개 순위를 독점하던 현상, `Q11`에서 8개 회차가 중복 노출되던 문제를 완전히 해결했습니다.

### 4.2 270만 자 이상치 강좌(`KPC_46980_149684` - 성과관리실무)의 영향 분석
- **정제 전**:
  - 135.5만 자 Base64 인라인 이미지로 인해 문서 벡터 Norm이 수만 배 폭증하여, `Q04` (직무분석 및 KPI 성과평가) 질의에 대해 **TF-IDF와 BM25 모두 상위 2,000위 밖으로 완전히 탈락**했었습니다.
- **정제 후**:
  - 노이즈 제거 후 883자의 정제된 텍스트로 복원되었으며, 핵심 커리큘럼(BSC, MBO, KPI Tree, 성과 대시보드) 토큰이 정상적으로 인덱싱되었습니다.
  - 비정상적인 길이 패널티가 소멸되어 관련 검색 질의에서 정상적인 점수를 획득할 수 있는 물리적 기반이 마련되었습니다.

### 4.3 ⚠️ 결과 변화와 품질 향상의 엄격한 구분
- **중요 안내**: 검색 결과에서 상위 10개 중 약 2.1~2.2개 과정이 새롭게 유입되고 순위가 변동한 것은 **"노이즈 제거에 따른 순위의 물리적 정상화(Rank Shift)"**입니다.
- 아직 팀원 4명의 실제 정성적 평가(라벨링) 데이터가 입력되지 않았으므로, **"검색 정확도가 검증 완료되었다"거나 "품질이 향상되었다"고 단정할 수 없으며 단정해서도 안 됩니다.**
- 정확도 품질의 공식 판정은 팀원 4인의 블라인드 평가 시트가 취합된 후 `scripts/compute_evaluation_metrics.py`의 Precision@5 및 nDCG@10 계산을 통해서만 확인됩니다.

## 5. 임베딩 입력 데이터 준비 및 파일럿 데이터셋 사양

### 5.1 검색·임베딩용 정제 데이터 스키마 (`education_courses_search_cleaned.parquet`)
8,645건 전수에 대해 다음 필수 컬럼이 완전 무결하게 구성되었습니다:
- `course_uid`: 고유 교육과정 식별자 (ID 무결성 100% 검증)
- `provider`: 교육기관명
- `title`: 교육과정명
- `clean_search_text`: Base64/HTML/노이즈가 완벽 제거되고 과정명 가중치가 부여된 합성 텍스트

- `ncs_code_type`: `OFFICIAL_NCS_CODE` / `PROJECT_CUSTOM_KSA_ID` / `NONE`
- `ksa_candidates`: `[지식] ... | [기술] ... | [태도] ...` 후보 문자열
- `url`: 공식 수강신청 상세페이지 URL (연결성 100% 검증)
