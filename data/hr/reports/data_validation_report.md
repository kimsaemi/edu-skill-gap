# 데이터 검증 보고서 (2026-10-31)

1~4는 모델과 API 없이 저장소 데이터만으로, 5는 API 키를 등록한 뒤 고용24·공공데이터포털 API로 확인했다. 가격·일정 오류 65건을 고쳤고, 추천 빈자리 46개 중 12개 업무는 실제 공급 부족으로 판단했다. 고용24 사업주훈련 데이터에서는 노무관리 교육의 회차가 인사 범위 전체의 9%뿐이었다.

다시 실행하는 방법

```bash
python scripts/fix_catalog_data_errors.py      # 1) 가격·일정·시간 오류 정정
python scripts/build_off_topic_exclusions.py   #    수강권처럼 과정이 아닌 행 제외
python scripts/validate_catalog.py             # 1~2) 품질 점검 + 회차 중복 영향
python scripts/analyze_thin_task_supply.py     # 3) 추천 빈자리 원인
python scripts/eda_work24_employer_2026.py     # 4) 저장된 고용24 API 응답 EDA
python scripts/check_work24_live.py --apply    # 5) 고용24 일정 실시간 확인 (API 키 필요)
python scripts/collect_kmooc_hr_supply.py      # 5) K-MOOC 인사 강좌 (공공데이터포털 키 필요)
```

## 1. 데이터 오류 정정

추천 대상 과정 7,796개를 점검했다. 정정 내역은 `catalog_data_fixes.csv`에 과정별로 남겼다.

| 점검 항목 | 정정 전 | 정정 후 | 처리 |
| --- | ---: | ---: | --- |
| 가격 0원인데 '정액 유료' (한국생산성본부) | 41 | 0 | 제목에 '무료' 20건 → 무료 / 두산 협력기업 전용 6건 → 기업 문의 / 가격 비공개 15건 → 미기재 |
| 시작일이 종료일보다 늦음 | 2 | 0 | 2시간 과정 1건은 종료일=시작일, 14시간 과정 1건은 날짜를 알 수 없어 종료일 비움 |
| 교육 시간 0 이하 | 1 | 0 | '자유수강권'(과정 아님)으로 추천 제외 목록에 추가 |
| 가격 500만 원 초과 | 6 | 6 | 해외 연수·임원 과정의 실제 가격이라 그대로 둠 |
| 과정 ID 중복, 링크 빈칸, Base64 노이즈, 추천 결과에 제외 과정 | 0 | 0 | 정상 |

남은 품질 문제: 설명 없이 제목만 있는 과정 1,647개, 일정이 이미 지난 과정 682개(일정이 있는 3,974개 중).

## 2. 회차 중복의 영향

같은 기관에 같은 제목으로 여러 번 등록된 행이 2,210개다. 서로 다른 과정 제목은 5,413개다.

| 기관 | 행 | 서로 다른 제목 | 제목당 행 | 행 비중 | 제목 비중 | 추천 Top 3 비중 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 한국생산성본부(KPC) | 1,262 | 766 | 1.65 | 16.2% | 14.2% | 30.3% |
| 한국능률협회(KMA) | 1,648 | 440 | 3.75 | 21.1% | 8.1% | 16.7% |
| 휴넷 | 1,715 | 1,590 | 1.08 | 22.0% | 29.4% | 17.8% |
| GSEEK | 1,768 | 1,647 | 1.07 | 22.7% | 30.4% | 11.8% |
| 멀티캠퍼스 | 960 | 793 | 1.21 | 12.3% | 14.6% | 3.9% |

- 한 업무·수준의 Top 3 안에 같은 제목이 겹치는 경우는 0건이다. 기관 간 중복 제거는 동작한다.
- 하지만 Top 3에 든 과정은 39.2%가 여러 행으로 등록된 과정이다. 카탈로그 전체(19.5%)의 2배다. 여러 번 등록된 과정이 의미 검색 후보에 여러 번 들어가 뽑힐 기회가 늘어난 것으로 보인다.
- 서로 다른 제목 기준으로 보면 한국생산성본부(14.2% → 30.3%)와 한국능률협회(8.1% → 16.7%)는 추천에서 2배 이상 많이 나온다.
- 개선안(모델 필요): 후보를 뽑기 전에 같은 기관·같은 제목을 한 행으로 묶는다. 발표의 '기관 편중' 개선안과 같다.

## 3. 추천 빈자리 46개의 원인

빈자리는 업무 19개에 걸쳐 있다. 업무마다 핵심 키워드를 정해 추천 대상 과정의 제목과 설명을 셌다(`thin_task_supply.csv`).

- **공급 부족 12개 업무:** 그 업무를 제목으로 다루는 과정이 0~2개다. 설명에서 일부 단원으로 다루는 과정은 있다.
  - 0개: 직무기술서 갱신, 평가자 편향 분석, 성과급(PS/PI) 산정
  - 1개: 총인건비 예산, 정원·현원 관리, LMS 데이터 분석
  - 2개: HCVA 노동생산성, 채용 전략·채널, 온보딩 설계 3개 업무, 사내 소통 콘텐츠
- **예비분 부족 7개 업무:** 제목에 키워드가 있는 과정이 3개 이상이다. 추천 결과 파일이 업무·수준마다 상위 5개만 저장해, 제외 목록이 늘자 예비 후보가 없어졌다. 모델로 다시 계산하면 채워진다.
  - 직무분류체계, 직무가치평가, 평가 등급 배분, 리더십 파이프라인, 교육 마스터플랜, 교육 운영, 연말정산(19개)
- 공급 부족 12개 업무 중 11개는 제목에 키워드가 있는 중급 이상 과정이 0개다. 발표 H2(노무·보상·조직문화 공급 부족)를 업무 단위로 보강하는 근거로 쓸 수 있다. 다만 키워드는 팀이 정한 것이라 검토가 필요하다.

## 4. 저장된 고용24 API 응답 EDA

`work24_employer_2026_eda.md`에 표 전체가 있다. 10-28에 사업주훈련 목록 API를 인사 관련 키워드 15개로 검색해 저장한 응답(원본 18,693행)을 썼다. 키워드 검색 결과라 사업주훈련 전체 분포는 아니다.

- 중복을 뺀 회차 13,632건, 과정 741개, 기관 108곳.
- 인사 범위(인사·노무관리·인사·조직 소분류) 과정 195개, 회차 2,297건, 기관 31곳.
- **노무관리는 과정 50개, 회차 211건으로 인사 범위 회차의 9%다.** 인사 세분류는 과정 하나가 평균 17.2회 열리지만 노무관리는 4.2회다. 발표 H2(노무 공급 부족)를 공식 데이터로 뒷받침한다.
- 상위 5개 기관이 인사 범위 과정의 57.4%를 낸다(HR에듀센터 인사드림, 한국생산성본부, 중앙경제HR교육원, 한국표준협회, 휴넷).
- 회차의 83.3%가 정원 500명 이상인 대규모 원격 과정이다. 1인 훈련비 중앙값은 50,490원이고 노무관리는 120,000원이다.
- 공식 만족도는 세분류와 관계없이 중앙값 약 93~97점(92.9~96.7)이다. 점수 차이가 작아 추천 근거로 쓰기 어렵다는 H3 결론과 같다.

## 5. 고용24·공공데이터 API 실시간 확인 (10-31, API 키 등록 후)

`check_work24_live.py`로 고용24 목록 API(310L01·311L01)에서 2026-01-01 ~ 2027-12-31 회차를 다시 받고, 남은 회차가 안 보이는 과정은 과정별 일정 API(310L03·311D02)로 한 번 더 확인했다. 결과는 `work24_live_check.md`·`.csv`에 있다.

| 지금 상태 | 과정 수 |
| --- | ---: |
| 운영 중 | 298 |
| 개강 예정 | 261 |
| 운영 종료 (올해 회차가 모두 끝남) | 13 |
| 확인 필요 (일정 API에도 회차 없음) | 2 |

- `--apply`로 `work24_course_details.csv`의 운영 상태를 위 결과로 바꿨다. 고객 앱은 '운영 중'·'개강 예정'일 때만 운영 표시를 붙이므로, 끝난 15개 과정에는 표시가 더 이상 붙지 않는다.
- 목록 검색만으로는 60개 과정의 남은 회차가 안 보였다. 과정별 일정 API로 확인하니 그중 47개는 운영 중이거나 개강 예정이었다. 목록 검색 결과만으로 운영 종료를 판단하면 안 된다.
- 카탈로그에 없는 인사 범위(NCS 020202…) 새 과정이 278개 있다(국민내일배움카드 102, 사업주훈련 176). 넣으려면 모델이 있는 PC에서 `refresh_work24_courses_2026.py`를 실행해야 한다.
- 일정이 지난 과정 682개 중 고용24 과정은 11개뿐이다. 나머지는 한국생산성본부·한국능률협회·멀티캠퍼스 과정이라 API가 없고 기관 사이트를 다시 수집해야 한다.

## 6. 모델 재계산 (10-31, 모델 접속 허용 후)

Ko-SRoBERTa 모델을 내려받아 기존 임베딩과 같은 벡터가 나오는 것(코사인 1.0)을 확인한 뒤 다시 계산했다.

| 항목 | 이전 | 지금 |
| --- | ---: | ---: |
| 고용24 과정 | 574 (10-28 기준) | 560 (10-31 운영 중 291·개강 예정 269) |
| 카탈로그 | 9,089 | 9,075 |
| 추천 제외 목록 | 1,293 | 1,302 |
| 추천 3개를 못 채운 업무×수준 조합 | 46 | 5 |
| 추천 커버리지 | 83.0% | 98.1% |

- 고용24 과정은 `refresh_work24_courses_2026.py --refresh-all`로 바꾸고, 상세 페이지 설명(훈련목표·내용·NCS 능력단위)을 다시 붙였다. 바꾸기 전 파일은 `data/hr/processed/backup/`에 있다(저장소에는 올리지 않음).
- 새 추천에 섞인 무관 과정 3개('AI 활용 상품기획', '사업타당성분석실무', '주민참여예산제의 이해')는 '다른 직무' 규칙에 넣어 뺐다.
- 남은 빈자리 5개는 직무기술서 관련 두 업무(TASK_HR_D02_T02 양식 체계화, D02_T06 정기 갱신)다. 제목에 직무기술서가 들어간 과정이 카탈로그에 하나도 없어 실제 공급 부족이다.
- 발표 데이터도 모델로 다시 계산해 10-26 값을 쓰던 세 곳(영역별 공급, 민감도, 기관 편중 후보 단계)이 모두 10-31 값이 됐다. 의미 기준 하위 3개 영역(보상·노무·조직문화)과 H2 '부분 채택' 판단은 그대로다.
