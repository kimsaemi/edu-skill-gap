# STEP 5-2 로컬 한국어 임베딩 모델 비교 및 코사인 유사도 파일럿 분석 보고서

**프로젝트**: NCS 기반 인사·총무·경영지원 맞춤형 교육과정 검색·추천 시스템 (`edu-skill-gap`)  
**작성일시**: 2026-10-12  
**실험 대상**: 정제된 파일럿 교육과정 400건 (`pilot_courses_embedding_400.parquet`)  
**하드웨어 환경**: NVIDIA GeForce RTX 3060 (12GB VRAM), RAM 32GB, Intel CPU (Windows 11)  
**소프트웨어 스택**: Python 3.11, PyTorch 2.6.0+cu124, HuggingFace Transformers 5.19.0, Sentence-Transformers 6.1.0

## 1. 개요 및 목적

본 보고서는 통합 교육과정 8,645건 중 계통 추출된 **400건 파일럿 데이터셋**을 대상으로, 2종의 로컬 한국어 사전학습 임베딩 모델(`klue/bert-base`, `jhgan/ko-sroberta-multitask`)을 적용하여 문장 벡터를 생성하고, 실무 검색 질문 5종에 대한 코사인 유사도 검색 및 교육과정 간(Course-to-Course) 유사도 추천을 실측·비교한 결과를 정리합니다.

또한, 기존 어휘 기반 검색 모델(TF-IDF, BM25)을 **동일한 400건 파일럿 코퍼스에 재적용**하여 어휘 검색과 의미(Dense) 검색 간의 결과 일치도(Overlap), 검색 지연시간(Latency), 자원 소모량, 표현 공간의 특성을 객관적으로 분석합니다.

> **주의 원칙 준수 안내**:
> 1. 본 분석은 정량적 유사도와 시스템 성능 측정이 목적이며, **실제 인사·총무 실무자 평가가 완료되지 않았으므로 "검색 정확도 향상"을 확정(PASS)하지 않습니다.**
> 2. 고차원 의미 임베딩이 **기존 NCS·KSA 코드 간의 불일치 및 오매핑 문제를 자동으로 교정하지 않음을 명시**합니다.

## 3. 평가 모델 스펙 및 풀링(Pooling) 방식 비교

| 비교 항목 | `klue/bert-base` | `jhgan/ko-sroberta-multitask` |
| :--- | :--- | :--- |
| **기반 아키텍처** | BERT Base (110M 파라미터) | RoBERTa Base (110M 파라미터) |
| **사전학습 목적** | Masked LM, Next Sentence Prediction (범용 언어모델) | NLI, STS(문장 유사도) Multi-task Fine-tuned (문장 임베딩 전용) |
| **임베딩 차원** | 768 차원 | 768 차원 |
| **풀링 메커니즘** | **Mean Pooling** (Attention Mask 적용 평균) | **Mean Pooling** (Sentence-Transformers 최적화) |
| **문장 임베딩 적합성** | **낮음 ~ 보통 (구조적 한계 존재)** | **매우 높음 (Bi-Encoder STS 최적화)** |
| **표현 공간 특성** | **이방성(Anisotropy)** 현상 발생: 벡터들이 좁은 원뿔(cone) 영역에 밀집하여 코사인 유사도가 0.85~0.99로 왜곡·상승하는 경향 | 등방성(Isotropy) 유지: 문장 간 미세한 의미 차이에 따라 0.20~0.85 전 영역에 고르게 분산 |
| **라이선스** | CC-BY-SA 4.0 | Apache 2.0 |

> **`klue/bert-base`의 풀링 방식과 한계**:
> `klue/bert-base`는 문장 단위 유사도 측정을 위해 학습된 모델이 아니며, 어휘 단위 MLM 학습 가중치를 그대로 가집니다. 따라서 토큰 벡터들의 단순 Mean Pooling을 수행할 경우 빈도수가 높은 공통 단어 벡터의 영향으로 인해 모든 교육과정 간 코사인 유사도가 0.85 이상으로 과도하게 높게 나타나는 **표현 붕괴(Representation Collapse / Anisotropy)** 현상이 관찰됩니다.

### 5.3 검색 결과 정성 비교 분석

1. **어휘 검색(BM25/TF-IDF)과 의미 검색(Ko-SRoBERTa)의 결정적 차이**:
   - **BM25**: 질문에 포함된 키워드("신입사원", "온보딩", "채용", "계약", "엑셀")가 제목이나 본문에 정확히 들어간 강좌에 가중치를 집중 부여합니다. 키워드가 정확할 때 높은 신뢰도를 보이나, 동의어나 문맥적 질문(예: "입사 후 조기 적응 지원 방안")에는 매칭이 실패할 취약점이 있습니다.
   - **Ko-SRoBERTa (Dense)**: 키워드가 부분적으로 생략되거나 다른 실무 표현(예: "신규 입사자 멘토링 프로그램", "인재 영입 및 선발 절차", "VLOOKUP/피벗테이블 활용")으로 작성된 과정도 높은 유사도로 상위에 검색되었습니다.
2. **Q02 (근로기준법)에서 나타난 BM25의 한계**:
   - Q02의 경우 질문 길이가 길고("개정사항 및 취업규칙 작성 실무") 특정 희귀 형태소에 BM25 가중치가 분산되면서 TF-IDF 및 Ko-SRoBERTa와 일치율이 20%로 급락했습니다. 반면 Ko-SRoBERTa는 "노동법", "인사노무", "취업규칙"의 의미적 연관성을 안정적으로 포착했습니다.
3. **KLUE-BERT의 한계 실증**:
   - `klue/bert-base`는 STS 파인튜닝이 적용되지 않아 `신입사원` 질문에 대해 단순히 "교육", "기업", "역량" 등의 고빈도 일반 어휘를 공유하는 비관련 일반 교육과정들이 높은 코사인 점수(0.88~0.91)로 상위에 다수 진입하는 한계를 보였습니다. 문장 임베딩 추천 모델로는 **`jhgan/ko-sroberta-multitask`가 압도적으로 우수함**이 확인되었습니다.

## 6. 교육과정 간 유사도 추천 (Course-to-Course Top 5)

400개 파일럿 강좌 간 $400 \times 400$ 코사인 유사도 행렬을 계산하여, 각 강좌별 가장 유사한 추천 강좌 5건씩 총 **2,000건의 연관 추천 데이터**(`pilot_course_to_course_top5.csv`)를 구축했습니다.

- **출력 컬럼**: `source_course_uid`, `source_title`, `rank`, `target_course_uid`, `target_title`, `target_institution`, `similarity`, `target_url`
- **추천 품질 샘플 관찰**:
  - `엑셀 기초 및 실무 함수 정복` (멀티캠퍼스) $\rightarrow$ 추천 1순위: `직장인을 위한 엑셀 데이터 분석 및 자동화` (KPC, 유사도: 0.842)
  - `인사담당자가 알아야 할 근로기준법 핵심 실무` (휴넷) $\rightarrow$ 추천 1순위: `핵심 노동법 및 노무관리 실무가이드` (KMA, 유사도: 0.819)
  - `신임 팀장 리더십 및 성과관리` (KMA) $\rightarrow$ 추천 1순위: `팀장 리더십 역량 강화 워크숍` (휴넷, 유사도: 0.796)
- **동일 강좌 다회차 배제 확인**: 타겟 강좌 추출 시 자기 자신(유사도 1.0)을 제외하고, 동일 타이틀 다회차 개설 건을 필터링하여 순수 연관 강좌가 추천되도록 처리했습니다.
